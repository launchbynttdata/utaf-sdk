The UTAF SDK is available in multiple languages that share the same underlying architecture, approach and, in many case, interfaces. All core features for automating tests are supported in all languages while testing runtimes are different based on the language and testing type.

### .NET

The UTAF SDK for .NET comes with support for Rest Sharp for API tests and SpecFlow for UI and end-to-end tests.
